# Governed local PDF and signer packages

Apply `backend/migrations/001_governed_proposal_release.sql` and `backend/migrations/003_reviewed_pdf_signer_packages.sql` after the base schema on the selected PostgreSQL database. The migration adds append-only PDF bytes, signer packages, and handoff/acceptance events. The PDF bytes and SHA-256 digest are stored together, and the database verifies the digest. Protect and back up this database as sensitive contract storage.

In the governed release workbench, create a case from an **approved** proposal or SOW owned by the case creator. The case stores a digest of the reviewed source fields and version. Add a `draft_version` evidence entry with that digest and version, plus commercial, legal, and client approval evidence. Complete the human workflow to `export_queued`. The local renderer refuses a source whose content or version changed after the case was bound, then stores one immutable PDF per case. Download returns the exact stored bytes. `record_export` requires that PDF.

After export, a proposal manager or account owner can prepare a package for a named signer. The link token is shown once; only its SHA-256 digest is retained. An operator may record a **manual handoff attestation**. The token holder can then download the exact PDF and type the expected signer name while explicitly accepting its terms. The stored acceptance identifies the PDF digest, named signer, time, attestation, and an evidence digest. It is a token-based self-attestation; possession of the link does not independently verify identity.

The local path sends no email, calls no e-signature provider, and writes no CRM receipt. Production delivery and legally sufficient electronic signatures still require an authorized signer provider, identity and consent controls, webhook/receipt verification, contract tests, retention policy, and legal review. CRM delivery or opportunity receipt requires a configured CRM connector and its verified receipt. The existing legacy proposal/SOW export routes are separate from this governed package.
